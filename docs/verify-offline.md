# Verify OpenVoiceFlow dictation with Wi-Fi off

**Short answer:** Download and prepare a local speech model while connected; leave cleanup **Off** (or separately prepare a local Ollama backend); disconnect the Mac's network; then dictate a harmless phrase into a focused text field and observe whether transcription and paste complete. This is a *reproducible procedure*, not a claim that we ran it on your Mac. It covers native [v0.6.6](https://github.com/shimoverse/openvoiceflow/releases/tag/native-v0.6.6), source-checked November 14, 2026 (Pacific time).

## Prepare an online baseline

1. Install the native macOS 14+ app and finish onboarding. In **Settings → TRANSCRIPTION — ON THIS MAC**, choose a WhisperKit model and wait for its download/preparation to succeed. The default model is `base.en`; choosing another model may require a separate download. The [released transcriber](https://github.com/shimoverse/openvoiceflow/blob/f41879063e0ed8c8356dbba90c7dcb86d7844de9/native/Sources/OpenVoiceFlow/Transcriber.swift) downloads the selected model, and [onboarding](https://github.com/shimoverse/openvoiceflow/blob/f41879063e0ed8c8356dbba90c7dcb86d7844de9/native/Sources/OpenVoiceFlow/OnboardingView.swift) waits for readiness. Do not start the experiment with a pending download.
2. Under **AI CLEANUP**, turn **Clean up my dictation** **off**. Verify the provider is not active; the toggle-on path otherwise initially selects Anthropic. The [released UI](https://github.com/shimoverse/openvoiceflow/blob/f41879063e0ed8c8356dbba90c7dcb86d7844de9/native/Sources/OpenVoiceFlow/DashboardView.swift) and [cleanup factory](https://github.com/shimoverse/openvoiceflow/blob/f41879063e0ed8c8356dbba90c7dcb86d7844de9/native/Sources/OpenVoiceFlow/CleanupProvider.swift) distinguish the passthrough from cloud requests.
3. In **Settings → PRIVACY + UPDATES**, optionally turn **Share anonymous usage & leaderboard rank** off if you want fewer unrelated app requests during the test. Automatic signed update checks are a separate setting; turning off either is not necessary for local speech recognition. Consult the [privacy policy](../PRIVACY.md) before interpreting network traffic.
4. In a disposable text field, focus the cursor and dictate a harmless phrase *while still online*. Record the exact selected model and whether text appears. This baseline catches missing Microphone, Input Monitoring, or Accessibility permissions before they are mistaken for an offline failure. If it fails, use the [permission and paste troubleshooter](troubleshoot-dictation.md).

## Disconnect and repeat

Turn off Wi-Fi **and any other network path** your Mac uses (for example Ethernet, a phone hotspot, or VPN connectivity through another active interface). Confirm the Mac cannot load a new web page; merely hiding the Wi-Fi icon is not proof of disconnection. Do not change the model, cleanup mode, permissions, hotkey, or test app between the two takes. Focus the same field, hold the selected hotkey, speak a second harmless phrase, and release. Note whether the recording indication appears, transcription completes, and the text lands at the cursor; if paste is blocked, try manual **⌘V** and inspect the Accessibility grant. Record observations rather than claiming a universal speed or accuracy result.

If dictation stops at model preparation, reconnect and finish that model's download. If it records but does not paste, follow the [paste troubleshooting steps](troubleshoot-dictation.md). If you deliberately use **Ollama**, first install and prepare its chosen model online, verify it runs locally, select Ollama in the app, then repeat the baseline and disconnected trial; its separate server may be absent even though WhisperKit is ready. Do not test a cloud provider disconnected and conclude that the underlying transcription is cloud-based: the cleanup request is a later, optional text step.

**What this proves:** A successful disconnected trial on *your configuration* supports that speech recognition and the chosen cleanup path work without a live connection at that moment. It does not audit all background traffic, establish no retention, or prove future model downloads, updates, usage sharing, and cloud cleanup work offline. The [pipeline explainer](local-transcription-and-cleanup.md) separates these paths; the [privacy policy](../PRIVACY.md) lists the relevant network requests.

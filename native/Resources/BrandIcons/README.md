# Brand icon sources

These small marks are bundled only as identification fallbacks when the real
macOS app icon cannot be resolved. OpenVoiceFlow prefers the installed app's
own icon. Brand names and marks remain trademarks of their respective owners;
their presence does not imply endorsement.

| Files | Source | Asset license |
|---|---|---|
| `apple.svg`, `claude.svg`, `discord.svg`, `gmail.svg`, `googlechrome.svg`, `iterm2.svg`, `notion.svg`, `pycharm.svg`, `safari.svg`, `signal.svg`, `sublimetext.svg`, `telegram.svg`, `whatsapp.svg`, `zedindustries.svg` | [Simple Icons 16.29.0](https://simpleicons.org/) | CC0 1.0 |
| `slack.svg`, `visualstudiocode.svg` | [SVG Logos through Iconify](https://icon-sets.iconify.design/logos/) | CC0 1.0 |
| `microsoftoutlook.svg`, `microsoftword.svg` | [theSVG Color through Iconify](https://icon-sets.iconify.design/thesvg-color/) | MIT |
| `superhuman.svg` | [Superhuman's public favicon](https://superhuman.com/) | Vendor-provided identification mark |
| `panic.png` | [Panic's public touch icon](https://panic.com/) | Vendor-provided identification mark |

Simple Icons paths are given their catalog brand colors when bundled. The two
vendor-provided files are unmodified public site icons. All files are used
nominatively at small size next to the corresponding app name.
